## Run it

Open `index.html` in a recent browser, or serve this folder with a static web server. No build step, dependencies, account, or photo-upload server are required.

## Privacy and face preservation

Photos are loaded locally in your browser; the app does not upload them to a server. Motion transforms the whole original image layer and does not use generative AI, face replacement, or face regeneration. The app does not independently animate a person inside the photo.

The current export creates a six-second WebM file (video only, no audio). Browser support for canvas video recording is required; try a recent Chrome or Firefox if export is unavailable.

## Features

- Local photo upload (JPG, PNG, WEBP; up to 20 MB)
- Drag-to-position preview and directional adjustment controls
- Still, gentle drift, slow zoom, and pan motion presets
- Adjustable photo scale and optional title overlay
- Six-second preview timeline and WebM export with ssalimuto watermark
- Responsive editor layout
